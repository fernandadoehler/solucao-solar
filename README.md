# Solução Solar — Landing page

Landing page da Solução Solar: energia solar fotovoltaica, aquecimento de piscina, aquecimento solar e instalação de Wallbox.

Página única (`index.html`) com o logo em `assets/`, sem dependências de build. Fotos carregadas do Unsplash (uso comercial gratuito). Para visualizar, abra o arquivo no navegador ou rode:

```bash
python3 -m http.server 5173
```

## Antes de publicar

- Troque o número em `const WHATSAPP = "5500000000000"` (fim do `index.html`).
- Atualize telefone e e-mail no rodapé.
- Revise os números de economia e garantias com a equipe comercial.
